Panduan Aplikasi & Hosting Online

Aplikasi Historia Nusantara V2 dirancang khusus untuk guru IPS / Sejarah dalam menyampaikan materi Hindu-Budha secara interaktif.

Fitur Utama V2:

  • Profil Guru & Sekolah: Dapat disesuaikan sendiri sesuai identitas pengajar.
  • 7 Level Materi: Rangkuman lengkap mulai dari Teori Masuknya Hindu-Budha hingga Kerajaan Majapahit & Peninggalan.
  • Kuis Mandiri Berwaktu: Dilengkapi nyawa, sistem skor, XP, dan pembahasan materi interaktif.
  • Battle Kelompok (Lomba): Fitur baru untuk adu kelompok dengan papan skor langsung & timer kilat.
  • Import/Export Excel: Guru dapat menambah ratusan soal menggunakan file Excel (.xlsx).

Cara Upload ke GitHub Pages (Online):

  1. Simpan kode file ini dengan nama index.html.
  2. Buat Repository baru di GitHub (misal: sejarah-hindu-budha).
  3. Upload file index.html ke repository tersebut.
  4. Masuk ke menu Settings > Pages, lalu aktifkan branch ke main / root.
  5. Aplikasi siap diakses secara online oleh seluruh siswa di kelas!
